# 官方版本后台同步

## 目标

客户端版本（`clientVersion`）和资源版本（`resVersion`）不再依赖人工改设置。
后端在启动后立即检查一次官方版本接口，之后按可配置间隔在后台复查；
官方发布新版本时自动写入 SQLite `settings`，配置接口、登录校验和资源接口在
下一次请求时直接读到新值，不需要重启服务。

默认接口：

```text
https://ak-conf.hypergryph.com/config/prod/official/Android/version
```

官方返回示例：

```json
{"resVersion":"26-11-13-06-37-23-89286612","clientVersion":"2.7.91"}
```

## 运行机制

- `backend/app/official_sync.py` 使用标准库 `urllib.request` 请求接口，不新增运行时依赖。
- FastAPI 启动事件创建后台 asyncio 任务；关闭事件取消任务。
- 第一次检查在启动约 2 秒后执行，避免和数据库初始化抢锁。
- 每次检查读取最新设置，因此在 Web UI 修改开关、URL 或间隔后无需重启。
- 检查失败后最多 5 分钟重试一次；成功恢复后回到正常间隔。
- 支持 `ETag` / `If-None-Match`：官方返回 `304` 时保留当前版本，并尝试用上次
  成功响应中的官方版本回写被人工改动的本地值。
- 手动“立即同步”绕过“自动同步”开关，便于先验证接口再启用定时任务。
- 同一进程内使用线程锁串行化手动和后台同步，避免并发写入。

## 失败语义

以下情况只记录错误，不覆盖 `client_version` / `res_version`：

- DNS、TLS、连接超时等网络错误；
- HTTP 非 200（`304` 除外）；
- 响应超过 1 MiB；
- JSON 无效、缺少字段或版本号格式非法；
- URL 不是完整的 `http(s)` 地址。

最近一次成功的时间、官方版本和 ETag 会保留，下一次检查仍可继续使用 ETag。

## 设置项

| 设置键 | 默认值 | 说明 |
| --- | --- | --- |
| `official_sync_enabled` | `1` | 是否启用后台自动检查 |
| `official_sync_url` | 官方 Android 版本接口 | 可替换为镜像或其他平台接口 |
| `official_sync_interval` | `3600` | 检查间隔（秒） |
| `official_sync_client` | `1` | 是否把官方 `clientVersion` 写入本地 |
| `official_sync_res` | `1` | 是否把官方 `resVersion` 写入本地 |
| `official_sync_last_attempt` | 空 | 最近检查时间 |
| `official_sync_last_success` | 空 | 最近成功时间 |
| `official_sync_last_status` | `never` | `updated` / `unchanged` / `not-modified` / `error` / `disabled` |
| `official_sync_last_error` | 空 | 最近错误摘要 |
| `official_sync_last_client_version` | 空 | 最近一次官方客户端版本 |
| `official_sync_last_res_version` | 空 | 最近一次官方资源版本 |
| `official_sync_etag` | 空 | ETag 缓存 |
| `official_sync_etag_url` | 空 | ETag 对应的接口地址，换 URL 后自动失效 |

Web 管理台路径：`/admin/settings` 的“官方版本自动同步”面板。
状态 JSON：`GET /admin/settings/official-sync/status`（需管理员登录）。
手动同步：`POST /admin/settings/official-sync`，表单字段 `op=sync`。

## 与强制更新的关系

`force_update` 是独立的登录校验开关。开启“同步客户端版本”后，如果官方客户端
版本高于设备上的 APK，`/account/login` 会按现有逻辑返回 `result=2`。如果只想
跟随资源版本，关闭“同步客户端版本”即可；已经同步到新版本时，可在同一页面的
“版本与客户端强制更新”表单中手动改回。
