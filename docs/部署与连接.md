# 部署与连接

## 1. 环境

- Python 虚拟环境：`/root/Knight/.venv`
- 设备：`adb devices` 可见，已 root
- 端口：后端 `8443`，TLS 反向层 `4443`，设备 SDK 反向 `8444`

```bash
/root/Knight/.venv/bin/pip install -r backend/requirements.txt
/root/Knight/.venv/bin/pip install mitmproxy
```

## 2. 启动后端

```bash
cd /root/mingrifangzhouyun/backend
ARK_HOST=0.0.0.0 ARK_PORT=8443 nohup setsid ./start.sh > server.log 2>&1 < /dev/null &
curl -s http://127.0.0.1:8443/healthz
```

首次启动会自动建表。数据库：`backend/data/arknights.sqlite3`。

## 3. 创建账号

```bash
cd /root/mingrifangzhouyun
ADB_SERIAL=8.162.0.198:30135 ./scripts/seed_account.sh
```

默认手机号 `13800138000`，Token `lab_manual_token`，昵称 `博士`。脚本会同时写入设备 `HypergryphSdkPreferences.xml`。

## 4. 启动 TLS 反向层

```bash
cd /root/mingrifangzhouyun/bridge
nohup setsid /root/Knight/.venv/bin/mitmdump \
  --mode reverse:http://127.0.0.1:8443 \
  --listen-host 127.0.0.1 --listen-port 4443 \
  -w flows/reverse-$(date +%Y%m%d-%H%M%S).mitm \
  > reverse.log 2>&1 < /dev/null &
```

## 5. 连接设备

```bash
cd /root/mingrifangzhouyun
ADB_SERIAL=8.162.0.198:30135 ./scripts/connect_device.sh
```

脚本执行：

```bash
adb -s $ADB_SERIAL reverse tcp:8443 tcp:8443
adb -s $ADB_SERIAL reverse tcp:8444 tcp:4443
adb -s $ADB_SERIAL shell settings put global http_proxy :0
# 设备 hosts 与 443 -> 8444 的 nc 转发也会自动补齐
```

> **重要**：设备重启、adb 重连、USB 拔插后 `adb reverse` 会丢失，客户端会报“资源载入异常 1103”或“获取网络配置失败”。运行 `scripts/watchdog.sh` 或启用 `ark-watchdog.service` 会自动恢复。除 hosts 外，watchdog 还会解析设备侧 `as/game-config/ak-conf/launcher/ak-webview` 与 Alipay 的 A 记录，重建 app UID 专用 `ARK_LOCAL` nat 链；这样即使 Android netd/WebView 使用自己的 DNS 缓存，启动器与 SDK 仍会进入本地 8444。

### 5.1 面具模块（推荐，官方 APK 不改包）

```bash
./scripts/build_ark_module.sh
ADB_SERIAL=8.162.0.198:30135 ./scripts/install_ark_module.sh --activate
ADB_SERIAL=8.162.0.198:30135 ./scripts/ark_module_status.sh
```

模块把 `hosts`、mitmproxy CA、设备侧 `443 -> 8444` relay 和游戏 UID 的 `ARK_LOCAL` nat 链
固化到 `/data/adb/modules/ark-local`，开机自动执行；主机侧仍由 watchdog 维持 `adb reverse`。
详见 `docs/面具模块接入.md`。

## 6. 客户端

1. 启动明日方舟。
2. 首次会弹语音包选择：任选一项后确认。
3. 标题页点击“开始唤醒”。
4. 若出现协议更新弹窗，点“阅读并同意”。

如果弹出“同步身份信息失败（错误号 200）”，先检查 `/account/syncData` 是否同时刷新了 `status.lastOnlineTs` 与 `status.lastRefreshTs`。2026-11-23 又补了反向层 SDK 信封与过期 token 自愈；`/admin/development/adb.json` 的 `sdk_gateway.envelope_ok`、`token_heal_ok` 应同时为 `true`。

## 8. 健康检查 / 停止

```bash
ADB_SERIAL=8.162.0.198:30135 ./scripts/healthcheck.sh
ADB_SERIAL=8.162.0.198:30135 ./scripts/stop_all.sh
```

`stop_all.sh` 会停止 mitm 与 Python 后端、撤销 reverse、清空设备代理，并清理 `__pycache__`。

## 9. systemd 常驻

```bash
./scripts/install_services.sh
systemctl status ark-backend ark-mitm ark-watchdog
```

`ark-watchdog` 每 15 秒检查并恢复 ADB reverse、hosts、443→8444 转发、系统代理、后端与 TLS 反向层。
