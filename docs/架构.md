# 架构

## 目标

客户端运行在 ADB 设备上，登录、账号、同步、配置、战斗等请求全部由本机自研后端响应。设备只负责显示与输入，不需要云手机、远程桌面或官方游戏服务器。

## 数据流

```
Android 设备
  com.hypergryph.arknights 2.7.91
    │
    ├─ 游戏 API http://127.0.0.1:8443
    │    └─ adb reverse tcp:8443 → 本机 Python 后端 8443
    │
    └─ Hypergryph SDK https://as.hypergryph.com:443
         └─ /system/etc/hosts → 127.0.0.1
              → 设备 443 nc → 127.0.0.1:8444
              → adb reverse tcp:8444 → 主机 127.0.0.1:4443
              → mitmdump --mode reverse → Python 8443
```

系统 HTTP 代理必须保持 `:0`。资源地址 `hu` 直接指向 `https://ak.hycdn.cn/assetbundle/official`，不经过本机。

## 组件

| 组件 | 实现 | 作用 |
|------|------|------|
| `backend/run.py` | Uvicorn | 启动 FastAPI，默认 `127.0.0.1:8443` |
| `backend/app/routers/sdk.py` | FastAPI | SDK 启动、账号、U8 Token、商品列表 |
| `backend/app/routers/game.py` | FastAPI | 登录、syncData、同步、任务、签到、战斗与支付入口 |
| `backend/app/routers/features_*.py` | FastAPI | 战役、派驻、沙盒、活动、肉鸽、基建、仓库等 430 条 feature 路由 |
| `backend/app/feature_common.py` | Python | feature router 的统一鉴权、增量、奖励与持久化原语 |
| `backend/app/grants.py` | Python | 统一奖励入账与增量生成 |
| `backend/app/missions.py` | Python | 任务状态、奖励与点数 |
| `backend/app/battles.py` | Python | 战斗解密、结算、关卡推进 |
| `backend/app/game_data.py` | Python | `server/data/excel` 静态表读取与缓存 |
| `backend/app/routers/config_api.py` | FastAPI | 动态 network_config、强制更新、资源本地命中与回源 |
| `backend/app/mail_service.py` | Python | 邮件模板/实例、附件发放、领取幂等 |
| `backend/app/runtime_settings.py` | Python | 维护、版本、资源与更新设置 |
| `backend/app/official_sync.py` | Python | 后台同步官方客户端/资源版本，ETag 校验，失败保留旧值 |
| `deploy/magisk/ark-local` | Magisk/APatch 模块 | systemless hosts、系统 CA、443 relay、游戏 UID 路由；不改官方 APK |
| `backend/app/routers/admin.py` | FastAPI + Jinja2 | 用户控制台、邮件中心、资源上传与 Web 管理后台 |
| `backend/app/db.py` | SQLite | 账号、会话、请求日志、设置 |
| `backend/app/services.py` | Python | 账号创建、玩家数据、登录记录 |
| `bridge/local_redirect.py` | mitmproxy addon | 旧版 8080 代理方案，保留作参考；当前生产使用 reverse 模式 |
| `deploy/ark-*.service` | systemd | 后端、TLS 反向层、watchdog 常驻 |
| `scripts/watchdog.sh` | Bash | 自动恢复 ADB reverse、hosts、443 转发、后端与 mitm |

## 后端内部

```
FastAPI
  ├─ SessionMiddleware（Web UI 会话，scrypt 密码哈希）
  ├─ request_logger（写入 request_logs，最多保留 2000 条）
  ├─ SDK 路由
  ├─ 游戏路由
  ├─ 配置 / 资源路由
  ├─ /admin Web UI
  └─ 404（未知路径明确返回 route not implemented，不再用空 delta 兜底）
```

SQLite 文件：`backend/data/arknights.sqlite3`（不提交）。

核心表：

- `accounts`：uid、phone、token、nickname、banned、user_json
- `sessions`：登录设备与最后活跃时间
- `request_logs`：方法、路径、状态码、uid、IP、耗时
- `settings`：服务设置
- `orders`：订单、`granted` 发奖幂等标记、补发时间
- `battle_sessions`：battleId → stageId，供结算解析具体关卡
- `mail_templates`：邮件模板、发件人、标题、正文、附件 JSON 与有效期
- `mail_instances`：每账号邮件实例、领取状态、过期时间、领取时间与软删除标记

管理台写入路径：账号资料/货币/库存/资产/干员/编队直接更新 `accounts.user_json`；邮件写入
`mail_instances`，领取时在同一事务内更新 `user_json` 与领取状态；服务与更新设置写入 `settings`，
游戏登录、配置、资源和邮件接口在请求时读取最新值。

## 运行时边界

- `backend/`、`bridge/`、`scripts/` 是当前运行时。
- `deploy/` 是 systemd 部署单元；`scripts/install_services.sh` 一键安装。
- `reference/` 仅作协议参考；`server/data/excel` 由 `game_data.py` 只读加载任务、关卡、角色、签到与礼包表。
- 账号数据在 SQLite 中；从旧 Java/MySQL 迁移时，把 `account.user` 的 JSON 写入 `accounts.user_json` 即可。
