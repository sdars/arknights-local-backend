# 架构

## 目标

客户端仍然运行在 ADB 设备上，但所有需要访问官方服务器的请求都由本机服务端响应。设备只作为显示与输入终端，不再依赖云手机、scrcpy、远控桌面或官方账号服务器。

## 关键设计

### 1. 不替换客户端

后端直接兼容官方客户端的 HTTP REST 协议，客户端不需要改包、重签或安装模块。设备侧只做两件事：

- 通过 `adb reverse` 把设备的 `127.0.0.1:8080`、`127.0.0.1:8443` 转发到本机；
- 把系统 HTTP 代理指向 `127.0.0.1:8080`，让 SDK 的 HTTPS 请求进入 mitmproxy。

### 2. mitmproxy 只做“域名到本机后端”的映射

桥接层不实现业务逻辑，只把官方域名请求转发到本机后端，并把后端的响应转换成 SDK 期望的 `{status,msg,type,data}` 结构。

关键点：

- `as.hypergryph.com/user/info/v1/basic`：后端返回的 `data` 是对象，桥接层把它序列化成 JSON 字符串再包一层；
- `as.hypergryph.com/user/oauth2/v2/grant`：把 `code`/`token` 都替换成本地账号的 secret，保证 `/account/login` 能查到账号；
- `as.hypergryph.com/app/v1/config`：把 `enableAutoLogin` 改成 `true`，让客户端直接使用缓存的账号；
- `game-config` / `ak-conf`：返回后端生成的 network_config，其中 `gs` 指向 `http://127.0.0.1:8443`，`secure:false`，客户端因此走明文 HTTP，不再需要为游戏流量做 TLS 解密。

### 3. 账号模型

`account` 表的核心字段：

| 字段 | 说明 |
|------|------|
| `uid` | 后端自增 UID，客户端登录后拿到 `10000000` 这类值 |
| `phone` | 客户端展示的手机号 |
| `password` | MD5(password + 固定 Key)，仅用于账号密码登录接口 |
| `secret` | SDK token，也是 `/account/login` 的 `token` 字段 |
| `user` | 玩家全量数据 JSON，首次登录时由 `data/defaultSyncData.json` 初始化 |

`scripts/seed_account.sh` 会插入一个 token 为 `lab_manual_token` 的账号，并把同样的 token 写入设备的 `HypergryphSdkPreferences.xml`。这样客户端点“开始唤醒”时不会再走短信验证码，而是直接用缓存 token 登录本机后端。

### 4. 网络配置与版本

客户端在启动时会请求：

- `game-config.hypergryph.com/api/remote_config/1/prod/default/Android/network_config`
- `ak-conf.hypergryph.com/config/prod/official/network_config`

后者的 `content` 中包含 `funcVer`、`configVer` 和 `configs`。本项目使用 `funcVer=V059`、`configVer=5`，并在 `V059.network` 中设置：

```json
{
  "gs": "http://127.0.0.1:8443",
  "as": "http://127.0.0.1:8443",
  "u8": "http://127.0.0.1:8443/u8",
  "hu": "http://127.0.0.1:8443/assetbundle/official",
  "hv": "http://127.0.0.1:8443/config/prod/official/{0}/version",
  "secure": false,
  "devsdk": false
}
```

`devsdk` 必须是布尔值，不能是 `null`；`{server}` 占位符必须在返回前替换，否则客户端会报“网络配置解析失败”。

### 5. 安全边界

- Java 后端和 MySQL 只监听 `127.0.0.1`；
- 设备通过 `adb reverse` 访问本机，不需要把 8443/3306 暴露到公网；
- 如果把 `SERVER_URL` 改成局域网地址，请自行加防火墙，仅允许测试设备访问；
- `config.json`、`.env`、抓包文件和账号 token 不提交到 Git。
