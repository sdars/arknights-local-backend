## 2. SDK 登录

### 2.1 初始化配置

`GET https://as.hypergryph.com/app/v1/config?appCode=7318def77669979d&platform=1`

官方响应的 `data.app` 包含 `enableAutoLogin`、`enableAuthenticate`、`enableAntiAddiction`、`enablePaidApp` 等。桥接层强制：

```json
{"enableAutoLogin": true, "enableAuthenticate": false, "enableAntiAddiction": false, "enablePaidApp": false}
```

### 2.2 用户信息

`GET https://as.hypergryph.com/user/info/v1/basic?token=lab_manual_token`

后端响应（`data` 为对象，桥接层会转成字符串）：

```json
{
  "status": 0,
  "msg": "OK",
  "type": "A",
  "data": {
    "hgId": "1",
    "phone": "13800138000",
    "email": "13800138000",
    "identityNum": "10000000",
    "identityName": "13800138000",
    "isMinor": false,
    "isLatestUserAgreement": true
  }
}
```

### 2.3 OAuth grant

`POST https://as.hypergryph.com/user/oauth2/v2/grant`

请求：

```json
{"token":"lab_manual_token","type":0,"appCode":"7318def77669979d","deviceToken":"lab_manual_device"}
```

后端响应：

```json
{"status":0,"msg":"OK","type":"A","data":{"code":"lab_manual_token","uid":"10000000"}}
```

桥接层会把 `code` 和 `token` 都补成 `lab_manual_token`，并把 `uid` 补成 `10000000`，保证客户端后续 `/account/login` 的 token 能匹配数据库。

## 3. 游戏登录

### 3.1 `/account/login`

`POST http://127.0.0.1:8443/account/login`

实际抓到的请求体：

```json
{
  "uid": "10000000",
  "token": "lab_manual_token",
  "assetsVersion": "26-11-13-06-37-23-89286612",
  "clientVersion": "2.7.91",
  "platform": 1,
  "deviceId": "369a2a9637457ce8e91e38641fe7db3a",
  "deviceId2": "",
  "deviceId3": "",
  "networkVersion": "5",
  "udtVersion": "79.0.0"
}
```

响应：

```json
{
  "result": 0,
  "uid": 10000000,
  "token": "lab_manual_token",
  "secret": "lab_manual_token",
  "serviceLicenseVersion": 0,
  "data": {
    "result": 0,
    "uid": 10000000,
    "secret": "lab_manual_token",
    "token": "lab_manual_token",
    "serviceLicenseVersion": 0
  }
}
```

后端会检查：

- `clientVersion == version.Windows.clientVersion`（国服分支的兼容逻辑，配置中同时提供 `Windows`、`Android` 别名）；
- `assetsVersion == version.Android.resVersion`；
- `token` 能在 `account.secret` 中查到。

### 3.2 `/account/syncData`

`POST /account/syncData`，请求头带 `secret`、`uid`、`seqnum`，响应约 592 KB，包含：

```json
{
  "result": 0,
  "ts": 1795241602,
  "user": { "status": { "nickName": "博士", "level": 1, "...": "..." }, "...": "..." },
  "playerDataDelta": {"deleted": {}, "modified": {}}
}
```

首次登录时后端用 `data/defaultSyncData.json` 初始化 `account.user`，并把 `status.nickName` 设为 `博士`、`status.uid` 设为 `10000000`，避免客户端停在昵称输入/空账号状态。

### 3.3 战斗入口

`POST /quest/battleStart`

教学关请求体：

```json
{
  "isRetro": 0,
  "pry": 0,
  "battleType": 0,
  "multiple": null,
  "extra": null,
  "usePracticeTicket": 0,
  "stageId": "guide_01",
  "squad": null,
  "assistFriend": null,
  "isReplay": 0,
  "startTs": 1795241798
}
```

响应状态 200，客户端进入教学战斗。

## 5. 桥接规则

当前生产链路使用 mitmdump `--mode reverse`：设备 443 → `nc` → 设备 8444 → `adb reverse` → 主机 4443 → Python 8443。所有 `as.hypergryph.com`、`game-config`、`ak-conf`、`launcher`、`ak-webview` 请求都按原路径进入 Python 后端。

`bridge/local_redirect.py` 现在由 `ark-mitm.service` 通过 `-s local_redirect.py` 加载；它负责：

- `basic` / `grant` 包装为 SDK 信封（`data` 为 JSON 字符串）；
- `update_agreement` 直接返回成功；
- `app/v1/config` 改写 `enableAutoLogin=true`、`enableAuthenticate=false`。
- `openapi.alipay.com/gateway.do` 返回 302 到 `/pay/success?orderId=...`，把支付宝 page pay 变成可重复的本地闭环。


## 7. 邮件协议（静态类型对照）

对应 `dump.cs` 中的 `Torappu.MailMetaInfo`、`ListMailBoxRequest/Response`、
`ReceiveMailRequest/Response`、`ReceiveAllMailRequest/Response` 与 `RemoveAllRecievedMailRequest`。

| 路径 | 请求 | 响应 / 行为 |
|------|------|-------------|
| `POST /mail/getMetaInfoList` | `{from}` | `{result:[{mailId,surveyMailId,state,createTime,hasItem,type}]}`；普通邮件 `type=1` |
| `POST /mail/listMailBox` | `{mailIdList,sysMailIdList,surveyMailIdList}` | `mailList[] + surveyMailList[] + playerDataDelta`；附件字段为 `{type,id,count}` |
| `POST /mail/receiveMail` | `{mailId,type}` | 同一 SQLite 事务写 `user_json`，邮件置 `state=1`；重复领取返回 `result=1` |
| `POST /mail/receiveAllMail` | `{mailIdList,sysMailIdList}` | 批量领取未读邮件并合并 delta |
| `POST /mail/removeAllReceivedMail` | 同上 | 仅移除 `state=1` 的邮件，未领取邮件不会被误删 |
| `POST /mailCollection/getList` | `{}` | `{collections:[],extra:[]}`，避免空路由反序列化失败 |

邮件模板存于 `mail_templates`，实例存于 `mail_instances`；模板来自 `server/data/mail/mail_templates.json`，
启动时只补入不存在的模板。管理员发送后，`/account/syncData` 会更新 `pushFlags.hasGifts`。

## 8. 编队与更新设置

- `POST /quest/squadFormation`：`squadId + slots[<=12]`，校验 `charInstId` 属于 `troop.chars`，保留
  `skillIndex/currentEquip/currentTmpl/tmpl`，写回 `troop.squads`。
- `POST /quest/changeSquadName`：写回编队名称。
- `GET /config/prod/official/{os}/version`：动态返回 `clientVersion/resVersion`。
- `GET /config/prod/official/remote_config` 与 `/api/remote_config/1/.../remote_config`：返回 `forceUpdate`、`maintenance`。
- `GET /api/game/get_latest_game_info`：仅当 `force_launcher_update=1` 且填写 `update_url` 时返回 `action=1`（强制更新），否则 `action=0`；`update_type=0`，并返回客户端版本、包地址与更新说明。
- `/account/login`：维护中返回 `result=3`；客户端版本不一致且开启强制更新返回 `result=2`；资源版本不一致且开启强制资源更新返回 `result=4`。
- `GET/HEAD /assetbundle/official/{os}/assets/{hash}/{file}`：优先读取 `asset_root`，`.json/.meta/.txt` 使用 `no-cache`；本地缺失时 302 到 `asset_fallback_url`。
