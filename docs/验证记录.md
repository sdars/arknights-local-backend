## 4. 已知客户端提示

### 4.1 同步身份信息失败（错误号 200）

现象：登录后 U8/HG SDK 弹出“同步身份信息失败，请重试 / 错误号200”，但 `/account/login` 与 `/account/syncData` 均为 200，游戏数据已下发。

结论：这是客户端 SDK 对伪造 Token 的本地身份校验提示，不是后端接口失败。重试、重新唤醒或关闭弹窗后可继续进入游戏；后端日志与 SQLite 均能看到完整链路。

### 4.2 资源载入异常（错误号 1103）

根因已定位：设备 `adb reverse` 丢失，客户端连接 `127.0.0.1:8080` 时 `ECONNREFUSED`：

```text
java.net.ConnectException: Failed to connect to /127.0.0.1:8080
  ... ECONNREFUSED ...
GameUpdateSdk: getLatest callback: {"code":1103,...}
```

修复：重新执行 `adb reverse tcp:8080 tcp:8080` 与 `adb reverse tcp:8443 tcp:8443`，重启客户端后恢复正常。

## 5. 数据迁移
