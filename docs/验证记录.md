## 4. 已知客户端提示

### 4.1 同步身份信息失败（错误号 200）— 已修复

现象：登录后 U8/HG SDK 弹出“同步身份信息失败，请重试 / 错误号200”，但 `/account/login` 与 `/account/syncData` 均为 200。

根因：`/account/syncData` 只更新了 `status.lastOnlineTs`，没有同步 `status.lastRefreshTs`。客户端用旧的 `lastRefreshTs` 做身份同步校验，返回 200。

修复：`backend/app/routers/game.py` 中 `sync_data` 同时写入 `lastOnlineTs` 和 `lastRefreshTs`，并复用同一个 `ts`。

2026-11-22 复测：客户端从标题页点击“开始唤醒”，进度 60% → 进入“累计签到活动”页面，未再出现 200 弹窗。后端 `request_logs` 显示 `basic → grant → getToken → getAllProductList → login → syncData → syncStatus` 全部 200。

2026-11-22 16:01 复测（systemd 重启 backend/mitm 后）：ADB reverse 与 443 转发由 `ark-watchdog` 自动恢复，客户端再次“开始唤醒”进入游戏主界面（博士 Lv.1，ID 10000000），未出现 200/1103。

### 4.2 资源载入异常（错误号 1103）

根因已定位：设备 `adb reverse` 丢失，客户端连接本机端口时 `ECONNREFUSED`（旧方案 8080，现方案 8443/8444）：

```text
java.net.ConnectException: Failed to connect to /127.0.0.1:8443
  ... ECONNREFUSED ...
GameUpdateSdk: getLatest callback: {"code":1103,...}
```

修复：`scripts/watchdog.sh` 自动补齐 `adb reverse tcp:8443 tcp:8443`、`tcp:8444 tcp:4443`、设备 hosts 与 443→8444 转发。
