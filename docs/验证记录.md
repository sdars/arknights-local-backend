## 4. 已知客户端提示

### 4.1 同步身份信息失败（错误号 200）— 已修复

现象：登录后 U8/HG SDK 弹出“同步身份信息失败，请重试 / 错误号200”，但 `/account/login` 与 `/account/syncData` 均为 200。

根因：`/account/syncData` 只更新了 `status.lastOnlineTs`，没有同步 `status.lastRefreshTs`。客户端用旧的 `lastRefreshTs` 做身份同步校验，返回 200。

修复：`backend/app/routers/game.py` 中 `sync_data` 同时写入 `lastOnlineTs` 和 `lastRefreshTs`，并复用同一个 `ts`。

2026-11-22 复测：客户端从标题页点击“开始唤醒”，进度 60% → 进入“累计签到活动”页面，未再出现 200 弹窗。后端 `request_logs` 显示 `basic → grant → getToken → getAllProductList → login → syncData → syncStatus` 全部 200。

2026-11-22 16:01 复测（systemd 重启 backend/mitm 后）：ADB reverse 与 443 转发由 `ark-watchdog` 自动恢复，客户端再次“开始唤醒”进入游戏主界面（博士 Lv.1，ID 10000000），未出现 200/1103。

2026-11-22 22:00 补充：后续继续给 `dungeon.stages` 注入 `main_00-02#f#` 等字段或整份复制参考账号的 2,000+ 个 guide flag 时，200 弹窗会再次出现。逐项复测后的安全增量是：

- 仅增加 `main_00-02`..`main_00-10`，字段与模板完全一致；
- 不加 `#f#` 变体、不加 `noCostCnt`；
- 保留模板原有的 5 个 `obt/guide/l0-0/*` flag；
- `status.mainStageProgress=main_00-10`。

该组合登录后进入主界面，采购中心正常解锁，未再出现 200。

### 4.4 购买与奖励实际到账（2026-11-22 22:2x）

问题：`/pay/confirmOrder` 只返回 `receiveItems`，没有修改 `accounts.user_json`；任务、签到与战斗结算也只返回空
`playerDataDelta`。客户端当次展示到账，但重登/重启后物品与进度消失。

修复：

- 新增 `backend/app/grants.py`，统一处理 `CHAR_SKIN`、`PLAYER_AVATAR`、`CHAR`、`GOLD`、`DIAMOND`、
  `DIAMOND_SHD`、招募/寻访券、材料、凭证、礼包、家具、头像、主题等奖励，并生成实际 `playerDataDelta`。
- `/pay/confirmOrder` 在同一个 SQLite 事务内写 `accounts.user_json`，并写 `orders.granted=1`、
  `orders.granted_at`；同一订单重复确认不会重复发奖。
- 启动时执行 `backfill_paid_order_grants()`，为历史 `orders.status=1 AND orders.granted=0` 的订单补发。
- 新增 `/mission/confirmMission`、`confirmMissionList`、`autoConfirmMissions`、`confirmMissionGroup`、
  `exchangeMissionRewards`；奖励、任务状态与任务点数写入存档。
- 新增 `/user/checkIn`；签到奖励落库，同一天重复调用不再发放。
- `/quest/battleFinish` 支持解密客户端 `data`，按 `battleId` 解析关卡；写入关卡 `state/completeTimes`、
  金币、玩家经验、首通奖励、普通掉落、解锁下一关，并推进已有任务的通关进度。

真机账号 `10000000` 的 6 笔历史已支付订单已由启动补发落库。读回结果：

### 4.2 资源载入异常（错误号 1103）

根因已定位：设备 `adb reverse` 丢失，客户端连接本机端口时 `ECONNREFUSED`（旧方案 8080，现方案 8443/8444）：

```text
java.net.ConnectException: Failed to connect to /127.0.0.1:8443
  ... ECONNREFUSED ...
GameUpdateSdk: getLatest callback: {"code":1103,...}
```

修复：`scripts/watchdog.sh` 自动补齐 `adb reverse tcp:8443 tcp:8443`、`tcp:8444 tcp:4443`、设备 hosts 与 443→8444 转发。
